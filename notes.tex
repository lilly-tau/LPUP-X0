\leftline{\bf Scope:}
\noindent This document is a transcription of my notes on paper, lightly
cleaning various issues in form. As such the scope of this document is to
act as a vague estimate as to what work went into the construction of X0.

\leftline{\bf Usage:}
\code
	x < input > output\cr
\ecode

\leftline{\bf Description:}
\noindent Takes, from stdin, a sequence of whitespaec/comment delimited
tokens and treats their values as uppercase hexadecimal values (without error
for invalid characters). The low byte of each token shall be put to stdout.

\leftline{\bf Examples:}
\code
	\# "Hello World"&\cr
	48 69 6C 6C 6F 20 77 6F 72 66 64 21&\cr
\ecode
\medskip
\code
	B8 48 0E&\# MOV AX 0E48H\cr
	CD 10&\# INT 10\cr
	41&\# INC AX\cr
	CD 10&\# INT 10\cr
	B0 21&\# MOV AL, 21H\cr
	CD 10&\# INT 10\cr
\ecode
\smallskip\hrule
\vfil\break

\null\vfil

X0 takes in hex digits seperated by spaces and comments, which will cause the
least significant byte specified to be read.

In this vein we have the following functions:
\item{$\circ$}	{\tt getchar: void -> char}
	Returns a single character from stdin.
\item{$\circ$}	{\tt putchar: char -> void}
	Outputs a character from stdin.
\item{$\circ$}	{\tt iswsp: char -> bool}
	Returns whether or not the current character is a whitespace character.

And the following states:
\item{$\circ$}	{\tt \_start}
	The entry point of the program.
\item{$\circ$}	{\tt wsp}
	Skip whitespace/comments.
\item{$\circ$}	{\tt shiftin}
	Read hex digits until whitespace/comment.
\page

\code
	c = getchar()\cr
	wsp:\cr
	if c = '\char`\\n'\cr
	\qquad comment = 0\cr
	if comment of c = ' ' or\cr
	c = '\char`\\t' or c = '\char`\\r' or\cr
	c = '\char`\\n'\cr
	\qquad c = getchar()\cr
	\qquad goto wsp
	if c = '\#'\cr
	\qquad comment = 1\cr
	\qquad goto wsp\cr
	goto shiftin\cr
\ecode
\page

\code
	shiftin:\cr
	data = 0\cr
	.loop:\cr
	c -= '0'\cr
	if c > 9\cr
	\qquad c -= 7\cr
	c \&= 0Fh\cr
	data <<= 4\cr
	data |= c\cr
	c = getchar()\cr
	if c = '\#'\cr
	\qquad comment = 1\cr
	if comment or c = ' '\cr
	or c = '\char`\\n' or c = '\char`\\t'\cr
	or c = '\char`\\r'\cr
	\qquad putchar(data \& 0FFh)\cr
	\qquad goto wsp\cr
	goto .loop\cr
\ecode
\page

\vfil\break

\null\vfil

\code
	putchar:\cr
	save (c, comment, cl)\cr
	rdi = 1\cr
	rax = rdi\cr
	rdx = rdi\cr
	push data\cr
	rsi = rsp\cr
	syscall\cr
	pop data\cr
	load (c, comment, cl)\cr
	return\cr
\ecode

\noindent Note that data is always the argument to putchar.
\page

\code
	getchar:\cr
	save (data, comment, cl)\cr
	rax = 0\cr
	rdi = rax\cr
	rdx = 1\cr
	push 0\cr
	rsi = rsp\cr
	syscall\cr
	pop ret\cr
	return ret\cr
\ecode

\noindent Note that 'c' is a vessel for getchar and thus may be directly linked
via register.

\leftline{\bf Required Registers:}
\item{$\circ$} {\tt c: char -> al}
\item{$\circ$} {\tt data: byte -> dl}
\item{$\circ$} {\tt comment: bool -> bl}
\item{$\circ$} {\tt iswsp: bool -> bh}

\code
	shiftin:\cr
	\qquad xor dx, dx\cr
	.loop:\cr
	\qquad sub al, 30h\cr
	\qquad cmp al, 0Ah\cr
	\qquad jb 0f\cr
	\qquad sub al, 07h\cr
	0:
	\qquad and al, 0Fh\cr
	\qquad shl dx, cl\cr
	\qquad or dl, al\cr
	\qquad call getchar\cr
	\qquad cmp al, '\#'\cr
	\qquad je 0f\cr
	\qquad call iswsp\cr
	\qquad or bh, bh\cr
	\qquad jz 1f\cr
	0:
	\qquad call putchar\cr
	\qquad jmp wsp\cr
	1:
	\qquad jmp .loop\cr
\ecode

\leftline{\bf Version 2}

\noindent We forgot to put in an exit condition, and there were a few errors
bloating the filesize (alongside a basic errror in the shiftin routine haha).

\item{1.} getchar/putchar arent fixed functions in the pipeline and require
a call, of which there are multiple.

\item{2.} {\tt CL} is reserved unnecessarily

\item{3.} Forgot the exit condition.

As such:

\code
	\_start:\cr
	\qquad init vars\cr
	loop:\cr
	getchar:\cr
	\qquad syscall ...\cr
	\qquad if size is zero:\cr
	\qquad\qquad exit ...\cr
	\qquad al = result\cr
	wsp:\cr
	\qquad if al $=$ ' ' -> space\cr
	\qquad if al $=$ '\char`\\t' -> space\cr
	\qquad if al $=$ '\char`\\r' -> space\cr
	\qquad if al $=$ '\char`\\n' -> newline\cr
	\qquad if al $\neq$ '\#' -> shiftin\cr
	\qquad comment = 1\cr
	\qquad -> space\cr
	newline:\cr
	\qquad comment = 0\cr
	space:\cr
\ecode
\page

\code
	space:\cr
	\qquad if dh $\neq$ 0:\cr
	\qquad al -= 30\cr
	\qquad if al $>$ 9:\cr
	\qquad\qquad al -= 7\cr
	\qquad al \&= 0F\cr
	\qquad edx <<= 4\cr
	\qquad dl |= al\cr
	\qquad dh = 0\cr
	\qquad -> loop\cr
\ecode

\noindent al, dl, bl and dh are reserved:
\item{al:} getchar result.
\item{dl:} input data.
\item{bl:} comment flag.
\item{dh:} data set flag.
